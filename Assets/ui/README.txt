Pixel Art Asset Placeholders
============================

This folder contains placeholder text files for 2D pixel art assets.
Replace each .txt file with a 32x32 PNG (or other) image of the same name.

Suggested tools:
- Aseprite (paid)
- Piskel (free online)
- GIMP (free) with grid enabled
- Photoshop with pixel art presets

Naming conventions (feel free to adjust):
- heart.png   – health pickup
- coin.png    – currency
- key.png     – collectible key
- sword.png   – weapon
- shield.png  – defense

Feel free to add more assets as needed.
